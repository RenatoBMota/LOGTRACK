                         ⚡ INÍCIO RÁPIDO (3 MINUTOS)
═══════════════════════════════════════════════════════════════════════════════

PASSO 1: Verificar Python
═══════════════════════════════════════════════════════════════════════════════
  
  Abra o terminal/prompt de comando e execute:
  
  $ python --version
  
  Deve retornar: Python 3.8+ ou superior
  
  Se não tiver Python instalado, baixe em: https://www.python.org/downloads/


PASSO 2: Criar ambiente virtual
═══════════════════════════════════════════════════════════════════════════════

  Crie uma pasta para o projeto:
  
  $ mkdir monitor-separacao
  $ cd monitor-separacao
  
  Copie TODOS os arquivos do pacote para esta pasta.
  
  Agora crie o ambiente virtual:
  
  🐧 Linux/Mac:
  $ python3 -m venv venv
  $ source venv/bin/activate
  
  🪟 Windows:
  $ python -m venv venv
  $ venv\Scripts\activate
  
  Deve aparecer (venv) no seu terminal.


PASSO 3: Instalar dependências
═══════════════════════════════════════════════════════════════════════════════

  $ python -m pip install -r requirements.txt
  
  Aguarde a instalação (alguns minutos).


PASSO 4: Gerar templates HTML
═══════════════════════════════════════════════════════════════════════════════

  $ python generate_templates.py
  
  Deve criar a pasta 'templates/' com 12 arquivos .html


PASSO 5: Executar a aplicação
═══════════════════════════════════════════════════════════════════════════════

  $ python app.py
  
  Você verá:
  
  ✓ Usuário admin criado: admin@localhost / admin
  🚀 Monitor de Separação iniciando...
  📍 Acesso: http://localhost:5000
  👤 Usuário padrão: admin@localhost
  🔑 Senha padrão: admin


PASSO 6: Acessar o sistema
═══════════════════════════════════════════════════════════════════════════════

  Abra seu navegador e acesse:
  
  👉 http://localhost:5000
  
  Faça login com:
  Email:  admin@localhost
  Senha:  admin


🎉 PRONTO! O sistema está rodando!

                         🗂️ ESTRUTURA DO BANCO DE DADOS

Entidades:
  • User - Usuários do sistema
  • Separator - Colaboradores
  • OperationUnit - Filiais/Depósitos
  • OperationLocation - Locais de trabalho
  • LoadOperation - Operações de separação

═══════════════════════════════════════════════════════════════════════════════
                        🆘 SE ALGO DER ERRADO
═══════════════════════════════════════════════════════════════════════════════

❌ "Port 5000 already in use"
   → Outro programa está usando essa porta
   → Edite app.py e mude para porta 5001

❌ "ModuleNotFoundError"
   → Verifique se ativou o ambiente virtual: source venv/bin/activate
   → Reinstale as dependências: pip install -r requirements.txt

❌ "Database is locked"
   → Feche todas as instâncias da aplicação
   → Delete monitor_separacao.db
   → Reinicie

❌ "Forgot admin password"
   → Delete monitor_separacao.db
   → Reinicie a aplicação
   → Será criado novo admin: admin@localhost / admin

❌ Templates não encontrados
   → Execute: python generate_templates.py
   → Verifique se pasta 'templates/' foi criada

Mais ajuda em: INSTALACAO.md ou README.md

═══════════════════════════════════════════════════════════════════════════════
                         🚀 DICAS DE PRODUÇÃO
═══════════════════════════════════════════════════════════════════════════════

Para usar em produção (não recomendado com os settings atuais):

1. Mudar SECRET_KEY em app.py
2. Desativar debug mode: debug=False
3. Usar servidor WSGI: gunicorn -w 4 -b 0.0.0.0:5000 app:app
4. Usar banco PostgreSQL ou MySQL
5. Configurar HTTPS/SSL
6. Adicionar backups automáticos
